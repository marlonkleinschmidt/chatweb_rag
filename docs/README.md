# Documentação

Guidelines e padrões do **Assistente RAG para documentos**: uma aplicação web local onde o usuário envia PDFs, faz perguntas e recebe respostas em pt-BR com as páginas e trechos que as sustentam.

> **Estado atual:** o projeto ainda não tem código. Esta documentação resume as regras definidas no [PRD v2.1](../PRD.md), que é a fonte de verdade. Em caso de divergência, vale o PRD.
